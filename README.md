# Root & Bloom 🌳💧

Boruları çevirerek su kaynaklarını kurumuş ağacın köküne ulaştırdığın rahatlatıcı bir mobil bulmaca oyunu. Tüm kaynaklar bağlandığında ağaç ekranın ortasına gelir ve yeşerir.

## Oynanış
- Bir boruya dokun → 90° döner.
- Su kaynaklarına (damlalar) bağlı borular maviye döner.
- Ekranın ortasındaki ana köke **tüm** kaynakları bağla → ağaç yeşerir.
- **İpucu** (seviye başına 3), **Geri Al**, **Yeniden Başla**; ayarlardan ses ve seviye geçişi.

## Özellikler
- Sonsuz, her zaman çözülebilir, seed'li seviye üretimi (zorluk seviyeyle artar, 1–4 kaynak)
- 10 ağaç türü: Kiraz, Elma, Mor Salkım, Portakal, Akçaağaç, Söğüt, Manolya, Mimoza, Limon, Lavanta Jakarandası
- Pastel boru paleti, su akış animasyonu, yeşerme sahnesi, yıldız puanlama
- Tek dosya: HTML + CSS + JS, bağımlılık yok (yalnızca Google Fonts)
- İlerleme tarayıcıda (localStorage) saklanır

## Çalıştırma
`index.html` dosyasını tarayıcıda açman yeterli.

## GitHub Pages ile yayınlama
1. Repoyu GitHub'a gönder.
2. **Settings → Pages → Source: Deploy from a branch**, branch `main`, klasör `/ (root)`.
3. Birkaç dakika sonra `https://<kullanıcı-adın>.github.io/Root-Bloom/` adresinde oynanabilir.
